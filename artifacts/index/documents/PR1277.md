## Understand the rules

[PR1277-dd5c31990b29]
Review the identification requirements below to qualify as either primary or secondary ID.
The transaction ID requirements may vary for customers and non-Cayman Bank customers and by transaction type and amount.
Refer to the applicable procedure for specifics on the types of ID required for the transaction or service you are providing (for example, open account, account maintenance, teller transaction). Existing customers are encouraged to use these stronger forms of authentication when processing teller transactions and account maintenance: PIN validation with an inserted card or tapped card or device (phone, watch) One-time passcode (OTP) Acceptable types documented in the Identification Requirements - Teller Transactions procedure

[PR1277-c7a058dae615]
Do not accept a state-issued medical marijuana card as either primary or secondary ID.
A digital driver’s license is considered a companion document and does not replace the physical driver’s license requirement.
The primary and secondary ID cannot both be issued by the same entity (for example, DMV) and with the same ID number. Consider both documents to be the same ID (for example, state driver's license and state ID or nondriver's license issued by the same state). Obtain a different secondary ID.

[PR1277-a0bb905d8e58]
If the individual provides an ID document with a signature for the requested transaction, compare the signature on the ID with the signature on the transaction document. It must favorably resemble the signature on the transaction document (for example, check endorsement or signed account application).

[PR1277-1f48ce59b31c]
A sovereign citizen is a member of a political movement of people who oppose taxation, question the legitimacy of government, and believe that they are not subject to the law. They may request to open an account with ID documents claiming to use laws outside of state and federal law. Cayman Bank cannot open accounts for these individuals, even if they are persistent or claim the Bank is acting illegally.
Refer to the CSBB 1FC Program Document for additional details on OFAC situations.

## Primary identification requirements (U.S. and Foreign)

[PR1277-d1f29d9f4108]
A customer’s U.S. or foreign-issued ID is considered a primary ID if it meets all of these requirements:
An original physical document (not a digital ID or copy)
Issued in the name of the individual presenting the ID
Contains a document or ID number
Printed in English Exception: Quebec driver’s licenses printed in French are acceptable for transactions processed on TellerView.
Not expired. An expiration date is not required, but if on the ID, it cannot be expired. (see U.S. ID exception)
Has a photograph that compares favorably with the individual presenting the ID (see U.S. ID exception)

## Secondary identification requirements

[PR1277-a46ec82d201d]
ID not meeting the primary ID requirements is acceptable as secondary ID (or additional ID) if the ID meets all of these requirements:
An original physical document (not a digital ID or copy)
Issued in the name of the individual presenting the ID and matches the name on the primary ID presented
Printed in any language. Any branch employee can translate the ID’s foreign language or if unable to interpret, contact LanguageLine Solutions for assistance.
Not expired. An expiration date is not required, but if on the ID, it cannot be expired

[PR1277-cd7bf58b9f0e]
Contains at least one of the following: Presenter’s signature A photograph or physical description that compares favorably with the individual presenting the document
Issued by a business, education institution, or government entity. Examples include but are not limited to: Notes: The ID must meet all secondary ID requirements listed above. As noted above, Cayman Bank has additional requirements applicable to passports issued by Cuba, Iran, and North Korea. Refer to the Office of Foreign Assets Control (OFAC) Requirements procedure for related secondary ID requirements.

[PR1277-155ad61f519f]
Exceptions to secondary ID requirements
If the individual has an unexpired U.S. military ID, you can accept an expired state-issued driver's license or ID card as secondary identification.
The following are acceptable as secondary ID (without a signature or photograph): Birth certificate (minors only) Credit card or Debit/ATM card. A signature is not required. If one is present, verify the signature against the customer’s primary ID

## Identify customers with face coverings

[PR1277-4201669e2920]
When the customer presents a primary ID with a photograph or physical description, you must review and ensure the ID favorably resembles the individual presenting the identification. Exception: You can accept an unexpired state-issued ID card without a picture for individuals with religious beliefs prohibiting a photograph.

[PR1277-d4a0b45a99c9]
Customer is wearing a face covering (for example, mask, bandana, or sunglasses) preventing you from positively identifying them: Tell the customer you cannot verify their identity using their photo ID and offer the following options: Temporarily remove the face covering. Cayman Bank customers may provide PIN validation with an inserted card or tapped card or device (phone, watch) when systematically available and permitted for the transaction requested.
You cannot positively identify a customer: Direct to a transaction approver to determine how to proceed.
