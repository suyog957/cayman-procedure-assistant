## Understand the rules > Transactional exceptions

[PR2321-86388eecb056]
When a transactional exception is being approved (for example, waiving the identification requirement for a transaction), the exception must be documented on the Approval screen in the Comments field.
When the Approval screen is not available, document the transaction exception on the item and scan or re-scan into TellerView to capture the approval.
Approvers must not make exceptions to transactions they are processing (no self-approvals are permitted).
Only branch management or regional employees may approve transactional exceptions.
Transactional exceptions cannot be made for Bank Secrecy Act (BSA) regulatory procedure requirements. These requirements ensure compliance with legal and regulatory requirements.

[PR2321-747b81ad2f04]
Item cashing transactions only: Select the Other approval reason option when approving a transactional exception.

## Non-Branch Banking employee approvals Fraud Awareness and Loss Prevention

[PR2321-a27eb5bc9dd0]
Complete the following steps when a non-Branch Banking employee (for example, TPB) provides a transaction approval or reference code for a deposit, item cashing, purchase bank check, or debit memo post transaction. Two separate approvals are required for transactions requiring an approval or reference code from another line of business (for example, TPB, TMCS):
Other line of business approval or reference code: Documented in the Comments field on the Approval screen.

[PR2321-232e4dfda0db]
Transaction approval: From a Branch Banking employee (listed on the Approver menu or selected from the Search for Approver field on the Approval screen). Notes: TellerView will only allow Branch Banking employees with the appropriate transaction approval authority on Banker Profile to approve deposit, item cashing, purchase bank check, branch settlement, and debit memo post transactions. Do not attempt to use the employee from the other line of business (for example TPB, TMCS) as the approver on TellerView.
Obtain an approval or reference code by calling the proper department or other line of business (for example TPB, TMCS).

[PR2321-ea282933a32e]
Document the code in the Comments field on the Approval screen (for example, TPB Approval code AB12345). Item cashing transaction only: Select Line of Business Approval Code approval reason option when an approval or reference code was provided by another line of business.

[PR2321-359da1f53338]
Obtain a transaction approval from a Branch Banking employee with the appropriate transaction approval authority in Banker Profile, as outlined within this procedure. For transactions above the branch employees’ approval limits, obtain approval and an employee ID from a district manager, regional services consultant, or above with the appropriate transaction approval authority in Banker Profile. Note: Do not enter the other line of business employee’s information (for example, the Private Bank Service Team agent) in the Search for Approver field.
